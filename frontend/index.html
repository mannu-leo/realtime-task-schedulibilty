College OS Lab Reference

Formulas and priority rules applied

Rate Monotonic Scheduling (RMS)

Optimal static-priority scheduling. Priority is inversely proportional to Period \(T_i\). Shorter period = higher priority.

Earliest Deadline First (EDF)

Optimal dynamic-priority scheduling. Priority is assigned dynamically based on absolute deadline \(d_{i,k} = r_{i,k} + D_i\). Earliest deadline = highest priority.

College Viva & Theoretical Schedulability Explanations

Key concepts for professor evaluation and exam viva questions

Why does Liu-Layland bound fail while RTA passes?

Liu & Layland's bound (\(U_{LL} = n(2^{1/n}-1)\)) is a sufficient test, not a necessary test. As \(n \to \infty\), the bound approaches \(\ln(2) \approx 69.3\%\). Task sets with utilization between \(U_{LL}\) and \(1.0\) may or may not be schedulable. Exact Response Time Analysis calculates the exact critical-instant response time, resolving the exact schedulability.

EDF Optimality & Arbitrary Deadlines

Earliest Deadline First is an optimal dynamic scheduling algorithm on single processor systems. For implicit deadline systems (\(D_i = T_i\)), a task set is schedulable if and only if \(U \le 1\). If constrained deadlines exist (\(D_i < T_i\)), the exact condition requires Demand Bound Function (DBF) analysis \(h(t) \le t\) for all \(t \ge 0\).

In-Depth Algorithm Characteristics

Academic assessment of scheduling properties

Rate Monotonic Scheduling (RMS)

  • Priority: Static (Fixed based on \(1/T_i\))
  • Preemption: Preemptive
  • Implementation Overhead: Low (simple static priority queues in OS kernels)
  • Worst-case Schedulable Bound: \(n(2^{1/n}-1) \approx 69.3\%\) to \(82.8\%\)
  • Optimality: Optimal among all fixed-priority algorithms

Earliest Deadline First (EDF)

  • Priority: Dynamic (Changes with each job's absolute deadline \(d_{i,k}\))
  • Preemption: Preemptive
  • Implementation Overhead: Moderate (requires dynamic sorting or heap priority queue)
  • Worst-case Schedulable Bound: 100.0% (\(U \le 1\))
  • Optimality: Optimal among all dynamic preemptive algorithms

First-Come First-Served (FCFS)

  • Priority: Arrival Time order
  • Preemption: Non-Preemptive
  • Implementation Overhead: Lowest (simple FIFO queue)
  • Suitability: Poor for real-time periodic systems (causes severe deadline misses due to convoy effect)
